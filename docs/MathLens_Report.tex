\begin{abstract}
\noindent \textbf{MathLens} is an interactive, web-based laboratory designed to demystify linear algebra by bridging abstract matrix mathematics with real-world digital image processing. Digital images are fundamentally stored as two-dimensional numerical arrays (grayscale matrices) or three-dimensional tensor structures (RGB channels). MathLens allows students and educators to manipulate matrix elements, perform scalar operations ($c \cdot A$), decompose color channels, and apply linear coordinate transformations ($X' = A X$) in real time. This report documents the technical architecture, mathematical foundation, UI/UX design system, and component implementation of MathLens as constructed in the current codebase repository.
\end{abstract}

\section{Introduction}
% ==========================================

\subsection{Problem Motivation}
Linear algebra is a foundational pillar of modern computer science, machine learning, and computer vision. However, students frequently encounter difficulties transitioning from abstract algebraic manipulation (such as matrix multiplication or vector transformations) to spatial intuition. Traditional textbook approaches present matrices purely as static blocks of numbers without immediate visual feedback.

\subsection{Mathematical Visualization as a Learning Tool}
Digital images provide an ideal, intuitive medium for teaching linear algebra:
\begin{itemize}
    \item Every pixel is directly backed by an integer intensity value $v \in [0, 255]$.
    \item Matrix additions and scalar multiplications correspond directly to brightness shifts and contrast adjustments.
    \item 2D affine transformations ($2 \times 2$ matrices) physically rotate, scale, shear, and reflect pixel coordinates on an image grid.
\end{itemize}
By displaying a digital canvas side-by-side with its mathematical matrix representation, learners obtain instant visual confirmation of every algebraic operation.

\subsection{Project Objective}
The primary objective of \textbf{MathLens} is to create a responsive, high-performance interactive web laboratory where users can explore linear algebra concepts sequentially—from 8-bit grayscale intensity matrices up to 2D coordinate transformations—with 60fps live canvas rendering.

% ==========================================
\section{Problem Statement and System Overview}
% ==========================================

\subsection{Problem Statement}
To design and build an intuitive, zero-dependency client-side application that visualizes:
\begin1}
    \item How $M \times N$ numerical matrices form digital image pixels.
    \item How scalar multiplication ($c \cdot A$) modifies image contrast and channel intensities.
    \item How 3D color tensors decomposes into separate Red ($R$), Green ($G$), and Blue ($B$) 2D matrices.
    \item How $2 \times 2$ transformation matrices transform spatial coordinate vectors $\vec{x} \mapsto A\vec{x}$.
\end{enumerate}

\subsection{System Overview}
MathLens connects algebraic matrix definitions directly with spatial pixel grids. When a user edits a matrix cell, adjusts a scalar slider, or selects a transformation preset, MathLens evaluates the underlying linear algebra in real-time math engines and updates the HTML5 2D Canvas rendering synchronously.

\section{Implemented Learning Modules}
% ==========================================

The current codebase features a 7-step guided learning progression:

\subsection{Step 1: From Pixels to Matrices (\texttt{Step1Grayscale.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Demonstrates 8-bit grayscale pixel representation where intensity $v \in [0, 255]$.
    \item \textbf{User Interaction}: Switch between matrix presets (Black, White, Checkerboard, Gradient).
    \item \textbf{Visualization}: Linked $4 \times 4$ interactive pixel canvas and matrix grid.
\end{itemize}

\subsection{Step 2: Edit Individual Matrix Elements (\texttt{Step2CellEditing.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Introduces direct element manipulation and frame-by-frame value transitions.
    \item \textbf{User Interaction}: Edit any cell $A_{i,j}$ directly or trigger the smooth $+1$ frame animation ($0 \to 255$).
    \item \textbf{Visualization}: Synchronous canvas update with floating pixel value tooltips.
\end{itemize}

\subsection{Step 3: Scalar Brightness Operations (\texttt{Step3ScalarBrightness.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Demonstrates scalar multiplication $B = c \cdot A$.
    \item \textbf{User Interaction}: Adjust scalar multiplier slider $c \in [0.0, 2.0]$.
    \item \textbf{Visualization}: Live scalar equation display $c \cdot A = B$ with updated image brightness.
\end{itemize}

\subsection{Step 4: Single RGB Pixel Vector (\texttt{Step4SingleRGBPixel.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Introduces 3-element color vectors $\vec{v} = [R, G, B]^T$.
    \item \textbf{User Interaction}: Adjust R, G, B sliders ($0-255$) or choose color presets (Red, Green, Blue, Yellow).
    \item \textbf{Visualization}: Color swatch preview with expanded vector bracket representation.
\end{itemize}

\subsection{Step 5: RGB Channel Matrix Decomposition (\texttt{Step5RGBMatrices.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Decomposes a full RGB color image into three distinct 2D channel matrices ($R_{\text{matrix}}$, $G_{\text{matrix}}$, $B_{\text{matrix}}$).
    \item \textbf{User Interaction}: Select channels ($R$, $G$, $B$, or All 3) and edit any of the 16 unique cell values.
    \item \textbf{Visualization}: Color-coded channel grid ($R$: Red, $G$: Green, $B$: Blue) with live reconstructed RGB canvas.
\end{itemize}

\subsection{Step 6: RGB Channel Scalar Operations (\texttt{Step6RGBScalarMult.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Demonstrates uniform scalar scaling on 3D color tensors: $c \cdot [R, G, B]$.
    \item \textbf{User Interaction}: Modify color scalar factor $c \in [0.0, 2.0]$.
    \item \textbf{Visualization}: Individual R, G, B scaled matrices alongside total image brightness scaling.
\end{itemize}

\subsection{Step 7: 2D Matrix Coordinate Transformations (\texttt{Step7ImageTransforms.jsx})}
\begin{itemize}
    \item \textbf{Purpose}: Explores $2 \times 2$ linear spatial transformations $\vec{x}' = A \vec{x}$.
    \item \textbf{User Interaction}: Select presets (Identity, Rotate $45^\circ$, Rotate $90^\circ$, Scale $2\times$, Shear X, Reflect X) or manually adjust matrix elements $a, b, c, d$.
    \item \textbf{Visualization}: 2D Cartesian coordinate grid displaying original and transformed vector points.
\end{itemize}

\section{Implemented Mathematical Formulations}
% ==========================================

\subsection{Grayscale Pixel Matrix Representation}
An $M \times N$ grayscale image is defined as a matrix $A \in \mathbb{R}^{M \times N}$:
\begin{equation}
A = \begin{bmatrix}
a_{1,1} & a_{1,2} & \dots & a_{1,N} \\
a_{2,1} & a_{2,2} & \dots & a_{2,N} \\
\vdots & \vdots & \ddots & \vdots \\
a_{M,1} & a_{M,2} & \dots & a_{M,N}
\end{bmatrix}, \quad \text{where } a_{i,j} \in [0, 255] \subset \mathbb{Z}
\end{equation}

\subsection{Scalar Matrix Multiplication}
Given a scalar constant $c \in \mathbb{R}_{\ge 0}$ and base matrix $A$, the brightened matrix $B$ is computed as:
\begin{equation}
B = c \cdot A = \begin{bmatrix}
\text{clamp}(c \cdot a_{1,1}) & \dots & \text{clamp}(c \cdot a_{1,N}) \\
\vdots & \ddots & \vdots \\
\text{clamp}(c \cdot a_{M,1}) & \dots & \text{clamp}(c \cdot a_{M,N})
\end{bmatrix}
\end{equation}
where $\text{clamp}(x) = \min(255, \max(0, \lfloor x \rceil))$.

\subsection{RGB Tensor Channel Decomposition}
A color image $I$ is represented as a 3D tensor $I \in \mathbb{R}^{M \times N \times 3}$:
\begin{equation}
I(i, j) = \begin{bmatrix} R_{i,j} \\ G_{i,j} \\ B_{i,j} \end{bmatrix}, \quad R_{i,j}, G_{i,j}, B_{i,j} \in [0, 255]
\end{equation}

\subsection{2D Affine Linear Transformations}
For any point vector $\vec{x} = \begin{bmatrix} x \\ y \end{bmatrix}$, a $2 \times 2$ transformation matrix $A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$ maps coordinates via:
\begin{equation}
\vec{x}' = A \vec{x} = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} ax + by \\ cx + dy \end{bmatrix}
\end{equation}

\subsubsection{Rotation Matrix}
\begin{equation}
R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}
\end{equation}

\subsubsection{Scaling Matrix}
\begin{equation}
S(s_x, s_y) = \begin{bmatrix} s_x & 0 \\ 0 & s_y \end{bmatrix}
\end{equation}

\subsubsection{Shearing Matrix}
\begin{equation}
H(k_x) = \begin{bmatrix} 1 & k_x \\ 0 & 1 \end{bmatrix}
\end{equation}

\subsubsection{Reflection Matrix (X-Axis)}
\begin{equation}
M_x = \begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}
\end{equation}

\section{Implementation Details}
% ==========================================

\subsection{Mathematical Engines}
\begin{itemize}
    \item \texttt{src/core/mathEngine.js}: Exports utilities for matrix creation, scalar multiplication, clamping, and matrix validation.
    \item \texttt{src/core/transformEngine.js}: Implements $2 \times 2$ matrix-vector multiplication $\vec{x}' = A\vec{x}$ and transformation preset generators.
\end{itemize}

\subsection{Visualization Components}
\begin{itemize}
    \item \texttt{PixelCanvas.jsx}: Native HTML5 2D Canvas renderer with device-pixel-ratio scaling, crisp grid lines, and cell hover detection.
    \item \texttt{MatrixGrid.jsx}: Interactive matrix grid rendering bracketed inputs for live value editing.
    \item \texttt{RGBExplodedView.jsx}: 4-column tabbed channel matrix display supporting editable $R, G, B$ inputs.
    \item \texttt{CoordinateTransformCanvas.jsx}: HTML5 Canvas displaying Cartesian axis grids, basis vectors, and transformed vector points.
\end{itemize}

\section{Current Limitations and Future Scope}
% ==========================================

\subsection{Current Limitations}
\begin{itemize}
    \item Grid dimensions are currently optimized for $4 \times 4$ matrices for pedagogical clarity.
    \item Transformations are limited to 2D affine matrices.
\end{itemize}

\subsection{Future Scope}
\begin{itemize}
    \item Support for arbitrary $N \times N$ uploaded user images.
    \item 3D tensor visualization for convolutional neural network (CNN) feature maps.
    \item Eigenvalue ($\lambda$) and Eigenvector ($\vec{v}$) visual decomposition ($A \vec{v} = \lambda \vec{v}$).
\end{itemize}
