% 1. Introduction
\section{Introduction}
MathLens is an interactive web-based educational tool that connects linear algebra concepts with digital image processing. By treating digital images as numerical matrices and color tensors, MathLens enables students to manipulate matrix elements, apply scalar brightness operations, decompose RGB channels, and visualize 2D linear coordinate transformations in real time using HTML5 Canvas graphics.

% 2. Work Completed
\section{Work Completed}
The primary core of the MathLens application has been engineered and fully implemented. We have constructed a 7-step interactive laboratory pipeline, built real-time HTML5 canvas renderers, designed mathematical engine modules for matrix operations, created dynamic cell intensity editors with smooth frame animation, and implemented a dual-theme UI (Dark Mode and Light Olive Mode) with subtle ambient texture overlays.

% 3. Implemented Features
\section{Implemented Features}
The following 7 interactive learning modules are fully functional in the system:
\begin{enumerate}
    \item \textbf{Small Grayscale (Pixels to Matrix)}: Displays an 8-bit $4 \times 4$ pixel grid alongside its corresponding numerical matrix $A$. Includes matrix presets (Black, White, Checkerboard, Gradient).
    \item \textbf{Cell Editing}: Allows users to edit individual matrix cell values ($0-255$) with instant canvas updates. Features a smooth $+1$ value animation ($0 \to 255$) powered by 60fps \texttt{requestAnimationFrame}.
    \item \textbf{Scalar Brightness}: Demonstrates scalar matrix multiplication ($B = c \cdot A$) with an interactive multiplier slider $c \in [0.0, 2.0]$.
    \item \textbf{RGB Pixel Vector}: Introduces 3D color vectors $\vec{v} = [R, G, B]^T$ with live RGB color patch rendering.
    \item \textbf{RGB Channels Decomposition}: Decomposes a color image into individual Red ($R$), Green ($G$), and Blue ($B$) 2D channel matrices with 16 unique editable cell entries and a single-row 4-column tab bar selector.
    \item \textbf{RGB Brightness Scaling}: Applies scalar scaling across 3D color tensors ($c \cdot [R, G, B]$).
    \item \textbf{2D Coordinate Transformations}: Demonstrates linear transformation matrices ($\vec{x}' = A \vec{x}$) acting on 2D vector space coordinates (Rotation, Scaling, Shearing, Reflection).
\end{enumerate}

% 4. Mathematical Implementation
\section{Mathematical Implementation}
MathLens implements the following mathematical formulations:
\begin{itemize}
    \item \textbf{Grayscale Pixel Matrix}: An image is modeled as matrix $A \in \mathbb{R}^{M \times N}$ where $a_{i,j} \in [0, 255]$.
    \item \textbf{Scalar Multiplication}: For scalar $c \ge 0$, element-wise multiplication is computed as:
    \begin{equation}
        B_{i,j} = \min\Big(255, \max\big(0, \lfloor c \cdot a_{i,j} \rceil\big)\Big)
    \end{equation}
    \item \textbf{RGB Channel Tensor}: A color pixel is represented as a 3-element vector $\vec{v} = [R, G, B]^T$. Channel decomposition separates tensor $I$ into individual color matrices $R_{i,j}$, $G_{i,j}$, and $B_{i,j}$.
    \item \textbf{2D Linear Coordinate Transformation}: For coordinate vector $\vec{x} = [x, y]^T$ and transformation matrix $A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$:
    \begin{equation}
        \vec{x}' = A \vec{x} = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} ax + by \\ cx + dy \end{bmatrix}
    \end{equation}
    Standard matrices implemented include Rotation $R(\theta)$, Scaling $S(s_x, s_y)$, Shearing $H(k_x)$, and Reflection $M_x$.
\end{itemize}

% 6. Technical Implementation
\section{Technical Implementation}
The application is built using a modern client-side frontend stack:
\begin{itemize}
    \item \textbf{Frontend Framework}: React 19 with functional components and React Hooks for state management.
    \item \textbf{Build Tool \& Routing}: Vite for fast development bundling and React Router DOM for single-page routing.
    \item \textbf{Canvas Graphics}: Native HTML5 2D Canvas API used in \texttt{PixelCanvas.jsx} and \texttt{CoordinateTransformCanvas.jsx} for pixel rendering and vector space drawing.
    \item \textbf{Mathematical Engines}: Pure JavaScript modules (\texttt{mathEngine.js} and \texttt{transformEngine.js}) isolating math calculations from UI rendering.
    \item \textbf{UI Libraries}: Framer Motion for smooth tab selection animations and Lucide React for clean SVG icons.
\end{itemize}
