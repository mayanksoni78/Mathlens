% 1. Introduction
\section{Introduction}
MathLens is an interactive web-based educational laboratory designed to bridge linear algebra concepts with digital image processing. The user begins by selecting their learning experience mode: \textbf{Basic Intuition} for visual conceptual exploration or \textbf{Advanced Math} for detailed algebraic representations. By treating images as numerical matrices and color tensors, MathLens allows learners to manipulate matrix elements, execute scalar operations, decompose RGB channels, and transform 2D spatial coordinates in real time.

% 2. Work Completed
\section{Work Completed}
The complete 7-step interactive learning pipeline for MathLens has been engineered and deployed. We built custom HTML5 2D Canvas rendering components, core mathematical engine modules, dynamic matrix element editors with smooth $+1$ frame animations, and a responsive dual-theme user interface (Light Olive Mode with ambient dot texture overlay and Slate-Teal Dark Mode).

\section{Implemented 7-Step Module Pipeline}
The following 7 interactive steps have been implemented according to the learning progression:

\subsection*{Step 1: Small Grayscale Image \& Matrix Representation}
Begins with a $4 \times 4$ pixel grayscale image shown side-by-side with its numerical matrix $A$. Demonstrates that a completely black image corresponds to a zero matrix ($A_{i,j} = 0$) and a completely white image corresponds to maximum intensity values ($A_{i,j} = 255$). Values between $0$ and $255$ represent shades of gray, establishing that a digital image is a numerical array.

\subsection*{Step 2: Change Individual Matrix Elements}
Allows learners to edit individual matrix elements via number inputs or sliders. As elements change (e.g., $0 \to 50 \to 100 \to 150 \to 200 \to 255$), the pixel canvas updates instantly. Includes a smooth $+1$ value animation button ($0 \to 255$) operating at 60fps.

\begin{figure}[H]

    \caption{Step 2: Interactive Element Steppers ($0 \to 255$) and Smooth Frame Animation}

\subsection*{Step 3: Connect Matrix Operations with Image Brightness}
Introduces scalar multiplication $A' = kA$. When $k > 1$ (e.g., $A' = 1.5A$), pixel values increase and the image brightens; when $0 < k < 1$ (e.g., $A' = 0.5A$), values decrease and the image darkens. Values exceeding $255$ are automatically clipped to $255$.

\end{figure}

\subsection*{Step 4: Move from Grayscale to Colour Images}
Expands grayscale scalars into 3D color vectors $[R, G, B]^T$. Demonstrates pure Red $[255, 0, 0]$, pure Green $[0, 255, 0]$, pure Blue $[0, 0, 255]$, and composite colors such as Purple $[128, 0, 128]$. Learners vary RGB sliders independently to observe live color patch changes.

\subsection*{Step 5: RGB Channel Matrix Decomposition}
Extends color vectors across entire images represented as triple tensors $(R_{\text{matrix}}, G_{\text{matrix}}, B_{\text{matrix}})$. Features a 4-column tab bar selector allowing users to view Red-only, Green-only, Blue-only, or all 3 channel matrices with 16 unique editable cell entries.

\subsection*{Step 6: Apply Scalar Multiplication to Colour Images}
Multiplies all three RGB channels by a common scalar $k$: $R' = kR$, $G' = kG$, and $B' = kB$. Displays the original color image, RGB channel matrices, scalar multiplication slider, and resulting modified color image simultaneously.

Demonstrates pixel spatial coordinate transformations $X' = AX$, where $A \in \mathbb{R}^{2 \times 2}$ is a transformation matrix acting on coordinate vectors $(x, y)$. Includes presets for Identity, Rotation ($45^\circ$, $90^\circ$), Scaling ($1.5\times$), Shearing ($H_x$), and Reflection ($M_y$) rendered on a Cartesian coordinate grid canvas.

% 4. Mathematical Implementation
\section{Mathematical Implementation}
The mathematical engine implements the following core formulations:
\begin{itemize}
    \item \textbf{Grayscale Matrix Representation}: $A \in \mathbb{R}^{M \times N}$, $a_{i,j} \in [0, 255] \subset \mathbb{Z}$.
    \item \textbf{Scalar Brightness Multiplication}: For scalar $k \ge 0$:
    \begin{equation}
        A'_{i,j} = \min\Big(255, \max\big(0, \lfloor k \cdot a_{i,j} \rceil\big)\Big)
    \end{equation}
    \item \textbf{RGB Tensor Channel Decomposition}: Color tensor $I(i,j) = [R_{i,j}, G_{i,j}, B_{i,j}]^T$, scaled via:
    \begin{equation}
        \begin{bmatrix} R' \\ G' \\ B' \end{bmatrix} = k \begin{bmatrix} R \\ G \\ B \end{bmatrix}, \quad 0 \le R', G', B' \le 255
    \end{equation}
    \item \textbf{2D Linear Coordinate Transformation}: Coordinate transformation vector $X = [x, y]^T$ transformed by $A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$:
    \begin{equation}
        X' = AX = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} ax + by \\ cx + dy \end{bmatrix}
    \end{equation}
\end{itemize}

% 6. Technical Implementation
\section{Technical Implementation}
MathLens is developed using standard client-side technologies:
\begin{itemize}
    \item \textbf{Frontend Stack}: React 19 (functional components, React Hooks) and Vite v8.3.
    \item \textbf{Canvas Graphics Engine}: Native HTML5 2D Canvas API (\texttt{PixelCanvas.jsx} and \texttt{CoordinateTransformCanvas.jsx}).
    \item \textbf{Math Calculation Engines}: Pure JavaScript utility modules (\texttt{mathEngine.js} and \texttt{transformEngine.js}).
    \item \textbf{Icons \& Motion}: Framer Motion v13 and Lucide React icons.
\end{itemize}
